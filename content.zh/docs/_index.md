px-patch 是 OpenTTD 的一个新补丁，基于 OpenTTD JGRPP 版本开发，实现了：
1. 列车解挂与对接
2. 模块化机场
3. 玩家添加自定义调度计划且可命名，允许载具在调度计划中执行调度计划表
4. 禁止列车在车库等待与列车在车站修理选项

在阅读此文档之前，您应已经熟悉游戏 OpenTTD 和 JGR Patches。如果您还不了解这个游戏，可阅读[ OpenTTD 社区中文文档](https://ottdzh.readthedocs.io/zh-cn/latest/)、[JGRPP 社区中文文档](https://ottdzh.readthedocs.io/projects/jgrpp/latest/readme.html)

px patch 基于 gpl v2 许可证协议开源至 [GitHub](https://github.com/pulsexlb/OpenTTD-patches)，可在 [GitHub Release](https://github.com/pulsexlb/OpenTTD-patches/releases/) 上下载最新版本并保持更新。

*请注意：此分支大量使用大语言模型编写代码，项目可能不稳定。请及时在 Github Release 上获取最新版本，往往包含最新的问题修复*
